# vk_short
Клипо-кукловое мышление!


Исходный код проекта https://vk.com/club237276767 Клипо-кукловое мышление.

Для работы нужны:
```
ffmpeg
```

Из питон либ:
```
ffmpeg-python  
yt_dlp  
vk_api  
multitasking  
playwright
```

## Гайд.

### 1. Настройка группы и config
В нужной группе заходим в настройки - сообщения - сообщения включены
Затем идем в настройки для бота и ставим галочку разрешить добавлять в беседы.
Добавляем в созданную конфу т.к. бот работает только в конфах и даем админку а так же выключаем галочку добавлять в беседы.

Переходим во вкладку дополнительно - работа с API. Там Callback API и ставим все галочки в сообщениях. 

Теперь во вкладке ключ доступа жмем создать ключ и ставим все галочки. Копируем токен.
Вставляем его в переменную group_token
Так же берем айди группы и вставляем в переменную group_id

Теперь идем на https://vkhost.github.io/ и получаем токен от kate mobile

Вставляем его в user_token. 

Далее путь до папки проекта вставляем. Пример:
```
GLOBAL_PATH = Path(r"D:\projekt\klip_repost_git")
```

Вставляем прокси (они нужны ток для скачивания ТТ)

Затем имя для клипа и стандартное описание, это когда не копируется описание у вк клипа с помощью !описание


### 2. Получение куков

Запускаем 
```
python get_cookies.py
```
Затем открывается браузер там логинимся под нужным акком (под тем же от лица которого брали токен группы, главное чтоб админом был короче)

Когда залогинились жмем энтер и все. Куки получены 

### 3. Старт

Запускаем бота
```
python main.py
```
Если ошибок не вышло то вы молодцы. 

Если ошибок не вышло то вы молодцы. 

Теперь скидываем клип в беседу и ждем. Бот скачает клип, уникализирует его и зальет в вк, а затем отправит в беседу его. Чтобы скопировать описание клипа пришлите его с пометкой !описание

С Тиктоками точно так же. Кидаем ссылку на тик ток и получаем вк клип. Прокси нужны именно для него. Почему то но этот вариант занимает больше времени чем вк клипы. Так же уникализирует клип.
